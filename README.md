# Crispy Cloud Website — GitHub Pages

A responsive product showcase website for Crispy Cloud. It displays the seven dessert sandwich flavors and brand information. It is a catalog/brand showcase only: **no cart, ordering, checkout, or delivery features**.

## Publish on GitHub Pages
1. Create a new repository on GitHub, for example `crispy-cloud-showcase`.
2. Extract this ZIP file.
3. Upload `index.html`, `style.css`, the `script.js` file if present, and the entire `assets` folder to the repository root. (The site does not require a backend.)
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## SEO included
Title, meta description, relevant keyword metadata, Open Graph metadata, semantic headings, descriptive image alt text, responsive layout, and text describing the Japanese-inspired deep-fried sandwich concept.

## Before publishing
Replace any placeholder location/contact details in About/Contact with your verified business information. GitHub Pages hosts the static site; it does not create the repository automatically.
